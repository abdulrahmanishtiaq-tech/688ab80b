# Digital Invitations

- `index.html`, `style.css`, `script.js`: the marketing website.
- `invitation-demo/`: the live Lavender Romance invitation (envelope video intro).
- Edit the settings block at the top of each `script.js` / invitation file (WhatsApp number, prices, dates).

## Run it in VS Code
1. File > Open Folder > choose this folder.
2. Install the Live Server extension.
3. Right-click `index.html` > Open with Live Server.
